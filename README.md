# GeoLog Technologies Website

Static website ready for GitHub and Vercel.

## Deploy
1. Upload the contents of this folder to a GitHub repository.
2. In Vercel, choose **Add New > Project** and import the repository.
3. No framework/build command is required. Deploy as a static site.

## Before publishing
- Replace `hello@geolog.example` with a real organization email.
- Add the phone number when available.
- Keep product/customer claims accurate and update roadmap items as they are actually built.
